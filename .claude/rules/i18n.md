# Rule: i18n (ES/EN)

- **Toda cadena visible** se obtiene con `t('namespace.key')` (`useTranslation` de `react-i18next`).
  Nunca texto fijo en JSX/TSX.
- Cada clave nueva DEBE existir en **ambos** catálogos: `web/src/i18n/locales/es.json` y `en.json`.
  El español es el idioma por defecto; el inglés es el fallback.
- Namespaces existentes: `common, auth, nav, dashboard, technicians, credentials, tickets, ticketForm,
  ticketDetail, comments, share, mobile, public, publicError, status, priority, wiki`. Agrupa por pantalla.
- Etiquetas de estado/prioridad: `t('status.<key>')` y `t('priority.<key>')`. No hardcodees labels.
- Fechas/horas: formatea con `Intl` y zona `America/Costa_Rica` (ver `web/src/lib/time.ts`).
- Se traduce la **interfaz**, no el contenido que ingresa el usuario.
- Atajo: usa el skill `/add-i18n-keys` para agregar/validar claves en ambos idiomas.
